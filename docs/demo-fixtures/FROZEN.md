> **证据强度**：`工作区（无未提交、无未跟踪）` = **等价于 HEAD**（前提 `git status --short` 为空），最强且最便宜，不必再导副本；`工作区（含未提交 N 个文件）` 只证明这棵树、**不能断言 HEAD**；`干净副本` 等价 HEAD，但树已干净时属浪费。冻结日只需在干净树上跑一次。
