# variants · 解析歧义备选（**非演示主素材，默认不进录像**）

> 维护：映像官。主素材是上一层目录的 `notice.txt`（15 条 / 3 冲突），**本目录任何文件都不许替换它**，除非走下面的批准流程。

## 这两份是干什么的

镜头① 需要一个"解析真实翻车"的现场。如果 10-22 复核时发现主素材上翻车点不复现（解析器修好了、`notice.txt` 一次全对），就用这里的备选换素材、重录镜头①。它们**只针对一类歧义**，不做全功能演示：

| 文件 | 针对的歧义 | 预期翻车形态 |
| --- | --- | --- |
| `A-相对时间歧义.txt` | 「这两周」「从下周开始」「下下周三」「月底前」「这周五→下周一」的边界 | 相对词算错日 / 「这两周每周…」被展开成多条 / 生效起点错位 |
| `B-条件顺延歧义.txt` | 「下雨顺延」「如遇雨改线上」——顺延到哪一天、原时段是否保留 | 自行编一个顺延日期 / 顺延后旧任务不取消 / 条件句被当确定时间 |

## 使用流程（必须四步全走完）

1. **只有映像官能决定启用**，且必须先在 10-22 复核会上说明"主素材翻车点不复现"
2. 复制备选内容**覆盖** `docs/demo-fixtures/notice.txt`（不要并存两个文件，全仓唯一路径原则不变）
3. `EXPECTED-2026-10-19.md` **整表重算**（不许只改几个数字），并把本节场景登记进去
4. 重跑 `npm run parse`，把真实输出贴进分镜附录 A ③，再改镜头① 旁白

## 禁止

- 禁止直接拿本目录文件当主素材录制（会导致视频里的数字和 EXPECTED 对不上）
- 禁止与 `notice.txt` 混用或互相引用
- 禁止只改素材不改 EXPECTED
