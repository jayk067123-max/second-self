## 一、机器与系统层（开录前一次性设置）

| 项 | 设成什么 | 为什么 |
| --- | --- | --- |
| 电源 | 插电，电源模式「最佳性能」 | 电池模式下 RTX 4060 会降频，OBS 编码丢帧 |
| 显卡 | NVIDIA 控制面板 → 管理 3D 设置 → 首选图形处理器 **高性能 NVIDIA 处理器** | 笔记本双显卡默认可能走核显，NVENC 用不上 |
| 刷新率 | 屏幕保持 240Hz 也行，但 OBS 输出固定 **60fps** | 240 帧录制文件巨大且平台只转 60 |
| 显示缩放 | 100%（2560×1600 下 125% 会让字体渲染发虚） | 保证录出来锐利 |
| HDR | 关闭 | 开着会导致录出画面过曝发灰 |
| 通知 | 专注助手 → 仅优先通知 / 关全部；退出微信、QQ、企业微信、钉钉、Steam | 弹窗穿帮一次就得整段重录 |
| Nahimic | **退出进程 + 停服务**（任务管理器 → 服务 → `NahimicService` 停止；或开机启动项禁用） | 它会做环绕/降噪处理，把旁白处理成"电话音"，且会和 OBS 的降噪叠加失真 |
| 其他音频增强 | 声音设置 → Realtek 设备 → 关闭「音频增强」/空间音效 | 同上 |

## 二、OBS 参数（照抄，不用试）

### 视频
- 基础（画布）分辨率：**1920×1080**
- 输出（缩放）分辨率：**1920×1080**
- 常用 FPS：**60**
- 缩放过滤器：Lanczos（锐一些）

### 输出（设置 → 输出 → 输出模式切「高级」）
- 编码器：**NVIDIA NVENC H.264**
- 速率控制：**CBR**，比特率 **8000 Kbps**（1080p60 的做法，B站转码后不糊；6000 也够，但文字类画面 8000 更稳）
- 关键帧间隔：**2 秒**
- 预设：**P5（质量）**；调优：高质量；多重通道：两次编码（two passes）
- 配置文件：high
- 录像格式：**mkv**（崩溃不丢文件）+ 勾选「录制结束后自动重混为 mp4」
- 文件路径：`C:\Users\y8702\Desktop\DS-项目集\03-演示视频\raw\`

### 16:10 屏幕怎么处理（关键，别踩）
屏幕是 2560×1600（16:10），成片要 16:9。**不要全屏采集再拉伸，也不要在 1080p 画布上留上下黑边。**

做法：**让被录的窗口本身就是 16:9**。
1. 浏览器开 F12 → 设备模式 → 自定义尺寸 **1920×1080**（或把浏览器窗口手动拖到客户区 1920×1080）。
2. OBS 加「**窗口采集**」（Windows 10 1903+ 的 `Windows 图形捕获` 方式），选浏览器窗口，取消勾选「捕获鼠标光标」，改由 OBS 全局鼠标高亮渲染，光标才不会闪。
3. 源右键 → 变换 → **比例适配屏幕（Fit to screen）**。因为窗口已是 16:9，铺满 1920×1080 无变形、无黑边。
4. 若某段必须录终端/IDE（16:10 界面）：单独建一个场景，把源裁成 16:9 区域（Alt 拖边缘裁剪），内容居中出现，宁可裁掉边栏也不要拉伸。

### 画面辅助
- 鼠标高亮：用 **ZoomIt**（Sysinternals 免费）。录制时按住 Ctrl+1 开聚光、Ctrl+3 画线，Windows 设置里打开「显示指针轨迹」会影响观感，别用。
- 点击反馈：OBS 加一个「光标高亮」滤镜或装 `obs-cursor-highlight`；也可用 ZoomIt 的实时缩放（Ctrl+4）在讲细节时推近。
- 画中画（真人出镜）：1080p 画布右下角 384×216，距离边缘各 48px，圆角 + 细白描边。

### 音频
- 麦克风设备：Realtek 内置阵列（当前唯一可用）
- 采样率 48kHz，声道**单声道**（旁白不需要立体声，文件更小）
- 滤镜链按顺序：**噪声抑制（RNNoise，非 RNNoise 选「噪音抑制（NVIDIA）」）→ 噪声门限 -35dB → 压缩器 3:1，阈值 -18dB → 增益 +3dB**
- 系统声音：单独一条音轨，音量 **-8dB**（别让点击音盖住旁白）
- 高级音频属性里勾选「轨道 1＝麦克风，轨道 2＝系统声」，输出到成片时混成一条

## 四、音频两条路线（二选一，B 为兜底）

**A. 有外置麦/耳机麦** → 正常配音。要求：离麦 15–20cm、加防喷棉、每段重录前听 5 秒回放；旁白语速控制在每分钟 220–260 字。

**B. 只有内置麦（当前状态）→ 字幕电影方案**
- 不追求配音；旁白全部做成**字幕条**，每句 ≤18 字，停留 ≥2.5 秒，位置在画面下方 1/5 处
- 配一段无版权 BGM，音量 **-20dB**，AI 生成过程保留原声打字音（真实感来源）
- 只在开头 15 秒和结尾 15 秒用真人语音（这两段可以反复录到满意）
- 这个方案在 **AI 协同复现段反而更强**：评委要读的是 Prompt 和报错文本，字幕比听语音更准
- 若用户能找到手机：用手机录旁白，剪映里按波形对齐到字幕节点，音质立刻上一个档

## 六、每次录制的 5 步 SOP

1. 打开脚本，确认本次要录哪几段、每段时长上限
2. 跑一遍演示路径，确认无报错、无加载卡顿（首屏加载慢就提前预热一遍）
3. OBS 里 **先录 10 秒黑屏+一段旁白**，回放确认画面不糊、声音不爆，再正式开录
4. 录制中：鼠标移动放慢到平时的 60%，每次点击后停顿 1.5 秒再继续
5. 收工立刻把 raw 文件改名 `S03_AI修复B01.mkv`（S＝分镜段号），防止剪辑时对不上
