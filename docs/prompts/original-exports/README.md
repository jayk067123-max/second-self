# 三条核心功能AI交互链

直接用浏览器打开以下HTML；无需联网，无需安装软件。

1. [分步录入与输入修复](01-分步录入与输入修复.html)：浮层录入需求 → 文档反馈输入框故障 → 定位焦点问题、修复与验证。
2. [图片上传与AI解析](02-图片上传与AI解析.html)：加号上传故障 → API接入反馈 → 配置、模型契约与展示迭代。
3. [补充重排与校验](03-补充重排与校验.html)：用户补充方案需求 → 输入与上下文修复 → 校验失败反馈、规则核查与验证。

## 来源与边界

- 来自同一真实Codex本机会话在2026-10-25发生的三个连续功能迭代区间；不是新编Prompt，不冒充最早原型开发，也不代表所有AI工具的全部历史。
- 每条保留该区间所有用户与可见AI消息，原时间、源行号、逐行SHA256及真实Git提交可核对；未纠正历史回复中的旧交付说法。工具调用与输出只选录相关支持项。
- 已恢复19张原始用户截图、www.docx的反馈正文与7张配图，以及第三条中原始粘贴HTML附件。第一条最初引用的“图片.docx”当前缺失，已在原位置标明，未补造；后续输入框故障的原始文档已恢复。
- 去除系统指令、推理与内部交接摘要；遮蔽密钥、报名个人信息和本机用户目录。没有删除用户的纠错。
- records.jsonl保留规范化原文；manifest.json列出来源快照哈希、区间、缺项、提交及导出文件哈希。原始私密会话不随公开仓库提交。哈希只说明一致性，不是平台签名。
