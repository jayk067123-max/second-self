# 016 · 直接采用用户提供的原版Orchard

日期：2026-10-25。本轮实际执行摘要，非原始聊天导出。

用户再次指出动画不符合预期，明确要求直接采用所提供HTML。本轮删除自绘SVG替代组件，直接嵌入原版p5/p5.brush绘画页面，保留其笔触函数、调色板、600像素画布、9秒绘制和1.5秒成画停留。仅调整容器尺寸、隐藏重复英文状态、降低像素密度和本地依赖路径。

此前的实现遇到系统减少动态设置会主动静止，可能造成用户看到静态画；没有取得用户浏览器设置，不能断言是其实际根因。现在减少动态时展示原版完成画，同时提供播放/暂停按钮，允许明确播放。正常模式沿用原版draw循环。

p5和p5.brush保存在public/animations/orchard，附许可证与来源说明。p5保留可读源文件。iframe仅允许脚本，无父页面数据访问。父页面状态与业务校验保持原逻辑。

已重新通过TypeScript、ESLint、30文件385项单测与生产构建。浏览器验证实际画布帧数与像素变化，不通过手动seek制造动态。完整专项结果见verification/original-orchard-checks.json；受控延迟/失败复用已有合成方案，本轮无新增付费模型调用。
