# 010 · 输入焦点、固定安排与空日期插画

日期：2026-10-25。依据参赛者提供的www.docx执行。本文件是当轮实施摘要，不是原始聊天导出，不替代缺失的历史核心Prompt链。

## 用户要求与改动

- 修复补充回答、用户名、地点等点击无法输入；检查其他表单。
- 删除设置中的学期开始日。保留存储、导入和演示数据内的周期起点，避免破坏既有日程。
- 三处“固定安排”共用简短说明：自动重排不移动，仍可手动修改。locked业务约束不变。
- 空日期从现有14幅SVG中随机切换，连续选择不同日期不重复，普通输入和重渲染不切图。

## 发现与纠正

撤除Sheet在blur时异步抢回标题焦点的处理；改为只在Tab/Shift+Tab到达边界时循环焦点，保留原生dialog、Escape关闭与关闭后焦点恢复。重排按钮加载时保持可聚焦，以aria-disabled/aria-busy表达状态并阻止重复请求，不再依赖全局blur抢焦点。分钟输入清空后不立即补0，避免键入时出现前导0。

早一轮262项界面检查使用fill写入部分字段，未覆盖鼠标点击逐字输入，不能据此证明这些输入已可正常操作。本轮补足实际点击与键盘输入验证。测试脚本曾因不符合时间块契约的受控响应、空库未持久化tasks、对数值输入的断言问题而中断，纠正后才形成最终通过记录。
