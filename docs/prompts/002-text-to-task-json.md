### 1.1 字段扩充评审记录（**已裁定，2026-10-18**）

原冻结清单 10 个字段装不下真值表要的三个语义。按第 ① 条约束「新增字段必须回到意图卡重新评审」，本卡执行了一次真实评审，结论如下——**这就是那条规矩第一次被真的用上，不是写在纸上的口号**。

| 新增字段 | 类型（定稿） | 真值表依据 | 评审结论与理由 |
|---|---|---|---|
| `repeat` | `{ kind: "weekly", byDay: number[] } \| null` | T03「每周二晚9点」= 单条 + `{weekly, byDay:[2]}`，**不许展开多条** | **扩为独立字段，不建独立实体**。理由：一条"每周二晚9点"是**一个承诺**，不是 N 个实例；展开会让"这一天有几件事"不可读，也让用户改一次要改 N 条 |
| `needsReview` | `boolean` | T12–T15 共 4 条为 true（无日期 / 须禁猜 / 有日期无时段 / 结束时间靠推断） | **扩字段**。解析质量信号：`false` 才允许直接入库，`true` 必须经人工修正表确认——这是"不许自动就信"的落地字段 |
| `locked` | `boolean` | T01/T02/T05/T11 为 true（调课、已确认会议、兼职排班、短会） | **扩字段**。用户权威标记：固定课/例会这类**不可被重排移动**的承诺；`reflow` 校验据此判定"固定课被挪 0 条"，非 0 直接作废方案 |

约定：`byDay` 用 ISO 星期（**1=周一 … 7=周日**）。字段总数 10 → **13**。

**落盘进度（2026-10-18 复核，以磁盘 + HEAD 实测为准）**：`schemas/task.ts` 现为 **10 冻结字段 + 5 可选扩展 + 3 个裁定字段全部落地**：

| 字段 | 状态 | 备注 |
|---|---|---|
| 10 个冻结字段 | ✅ 未改未删未改名 | 与下发原文一致 |
| `location` `flexible` `parentId` `progress` `estateMin` | ✅ 已加，全部 `.optional()` | 由逻辑手为 SPEC 规则2（同地点/跨校区）、规则1（`parentId`）、规则4（`progress`/`estateMin`）所加；**未经意图卡评审**，属"为让规则写得出来"的工程必需 |
| `locked` | ✅ `z.boolean().default(false)` | 已由 `.optional()` 改为**必填带默认**，符合裁定 |
| `needsReview` | ✅ `z.boolean().default(false)` | `TaskSchema` / `TaskDraftSchema` / `AiTaskDraftSchema` 三处均有，符合裁定 |
| `repeat` | ✅ `RepeatRuleSchema` | `{ kind: z.literal("weekly"), byDay: z.array(int 1–7).min(1) }`，与裁定结构完全一致；`Task`/`TaskDraft` 为 `.nullable().default(null)` |

⚠️ 仍有两处待办：①**`AiTaskDraftSchema` 的 `repeat` 是 `.nullable().optional()`**，另两处是 `.default(null)`——AI 输出契约允许省略该键，解析层必须按 `null` 兜底，否则"没吐 repeat"与"吐了 null"会被当成两种语义；②5 个可选扩展（`location` 等）仍属"工程必需但未走评审"，要么补一次意图卡评审认可为可选扩展，要么回退。

### 1.2 偏离归因清单（**预置，未发生**；真实踩到才回填 §4）

002 的偏离几乎必然出在这三处，届时对照归类，不要含糊写成"AI 解析错了"：

| 类型 | 判定特征 | 材料价值 |
|---|---|---|
| A. 相对日期算错 | 显式日期对、相对词（这周六 / 下周三 / 下下周三）边界错，或相对词与明写日期打架 | 中 |
| B. 重复规则丢失 | 「每周二晚9点」只生成一条普通任务、无 repeat 语义，或反向展开成 N 条 | 高 |
| C. 后文更正未覆盖前文 | 主素材 T04 三次【更正】/【再更正】并存，或 T07 的 18:30 未被"19:00 开始"覆盖——需要语义归并而非日期计算 | **最高**（真实模型最容易稳定复现，且最考验"人怎么引导收敛"） |
| D. 分段粒度错 | 一句话被拆成多条任务、非任务句（如「未请假缺课按旷课处理」）也成了任务，条数明显多于真值表 | 中高（2026-10-18 实跑已复现：24 条 vs 期望 15 条） |
| E. 抽取毁原文 | 用正则"挖走"时间串导致 `title` / `rawTextOrigin` 出现空洞（「中午 ，逾期不收」），破坏人工修正的溯源依据 | 中高（实跑已复现） |
| F. deadline 解析错 | 截止日期算错或年份错位（实跑：《大学物理》2026-10-25 输出成 2028-02-10） | **高**（硬错误，会污染冲突检测与预警） |
