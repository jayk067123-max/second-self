## 五、素材账（**防跨链混算**）

规则一：**证据只算给产生它的那条链。** 混算会让评委对不上账，一旦被发现，整份材料的可信度连带受损。

规则二（**全队写作规范，2026-10-18 主Bot 升格**）：**文档里一律不写死用例数量。** 统一表述为「以冻结日（2026-10-26）最后一次 `npm test` 实跑输出为准，原文作为附录附上」。确需给量级时只写下界（如「`conflicts` 60+ 项」），不写精确数。
> 原因：同一天内该数字变了五次（54 → 65 → 122 → 149 → 176），写进任何文档都会立刻过期。写「176」两小时后就是错的，不如写「以冻结日实测为准 + 附原文」。
