# 008 · 正式版融合与回归（2026-10-24）

## 用户原始意图
用户要求以已经确认的奶油色、草绿、黄色标题三标签页面为唯一最终界面，把全部可做的参赛工作完成；提交包只保留一份精炼正式版，并允许修改代码和同步仓库。原始用户消息另见 session-excerpt.md。这是本轮整理记录，不冒充历史原始对话。

## 检查结果与实施
- 原根页面跳转静态 HTML，而真实功能在另一路由。静态页面有固定解析结果和另一套 localStorage；现将三个标签接到同一 Zustand store、真实 API 与领域函数，旧路由重定向到根路径。
- 文本规则解析忽略明确日期；修正 ISO/短日期优先级、下周的自然周语义。回归另发现冒号时段被短日期正则误识别，增加时间边界防护。
- 修正周期时段显示与按日完成；周期截止只映射截止时刻，不虚构占用时间。
- 重排接收全量约束、所选日期、注入时钟与学期设置，服务端与写回前复用 guardPlan；固定、周期、已完成任务不能自动移动，不得排入过去，陈旧结果拒绝写回。相同方案去重。
- 本地新增、修改、删除、导入、清空和重排统一保留单步快照；撤销同时恢复任务、时钟和学期设置。存储失败给备份提示。
- 浏览器实际发现空存储水合一直加载；定位 persisted=undefined 的读取，已加空值处理。自动测试通过不等于浏览器流程通过，因此追加真实页面验收。
- 截图发现全局 button reset 覆盖 Tailwind utility，底色与内边距失效；移入 base layer。原密集表格改为逐条核对卡片，手机日期完整显示。

## 真实失败与修正
1. 日期正则曾把 9:00-10:30 的 00-10 当日期；加负向边界与月份范围后回归通过。
2. 周期截止筛选的 TypeScript 类型谓词过宽（TS2677），导致构建失败；改用编译器非空推导后恢复通过。
3. 浏览器自动化曾等待不存在的按钮名「采用」，实际按钮叫「用这套」；这是测试定位器错误，不能记成产品故障。改定位器后真实采纳和撤销成功。
