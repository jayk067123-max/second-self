# 第二自我

把通知、课表截图和随手记录整理成日程，发现时间冲突，再选择怎样调整。

![未来日程](docs/screenshots/future.png)

## 10分钟复现

环境：Node.js 22.13–24.x（推荐.nvmrc指定的24.14.0）、npm、中国时区。使用Node内置SQLite，无需单独安装数据库；首次安装依赖需要网络。

~~~sh
git clone https://github.com/jayk067123-max/second-self.git
cd second-self
npm ci
npm run dev
~~~

2026-10-26纯净副本实测：npm ci、verify及build合计约2分04秒，随后生产启动、注册和保存通过；当前网络与npm缓存环境，不含配置模型密钥。

打开 http://localhost:3000 。端口占用时运行 npm run dev -- --port 3022。
生产模式：npm run build，然后 npm run start。

1. 首次打开注册账号，之后登录找回自己的日程。
2. 在“添加”粘贴通知，或点绿色加号上传截图。
3. 补充缺失信息，核对日期和时间，确认后入库。
4. 在“未来”选择日期，查看冲突、生成重排，比较调整前后；可补充要求再调整。
5. 采用方案后可撤销；任务可编辑、删除、完成。头像设置支持导入、导出JSON。

首次启动为空日程。固定样例在 docs/demo-fixtures/demo-seed.json，可通过设置导入；导入会替换当前任务，先导出备份。演示时钟有明确标记，可返回实时。

## AI配置

复制 .env.example 为 .env.local，在服务端填写 LLM_BASE_URL、LLM_API_KEY、LLM_MODEL，然后重启服务。不要公开密钥。模型须兼容Chat Completions；图片入口须支持图像输入。详见 [配置说明](docs/AI-SETUP.md)。

未配置密钥时，文字与重排使用本地规则；图片识别会明确提示无法调用。AI结果需要校验和人工确认，不保证任意课表都识别正确。主动解析或重排会把相关内容发送给应用服务端及配置的模型服务商；已确认日程和个人设置按账号保存在应用服务端；浏览器保留账号隔离的缓存。

## 功能与边界

- 今天 / 添加 / 未来，共用任务与撤销状态；支持周重复、月历和搜索。
- 检查时间重叠、缓冲不足、日负荷和截止逼近。
- 固定、周期和已完成安排不可自动移动；采纳前再次校验。
- 等待界面随机播放花园、晨光、紫藤、玫瑰、锦鲤或橘子逐笔动画，统一2倍速；完整一轮约5.25秒后才显示结果。慢请求继续循环，主动关闭可取消。
- 注册、登录、退出；昵称、六个内置/自选头像、日程、完成状态与撤销自动保存。不同账号相互隔离。
- 断网修改保留本机，恢复连接重试；多处同时修改会提示选择版本。设置可导入原本机日程。
- 暂无密码找回、邮箱验证和系统推送，请妥善保存账号密码。

## 账号数据与部署

[登录界面](docs/screenshots/login.png) · 注册后进入本人日程。

默认保存到服务运行目录的data/accounts.sqlite，首次启动自动建表。ACCOUNT_DATA_DIR可指定持久化目录；重启仍保留数据。数据库、会话与真实密钥不进入Git或提交包，部署时应备份数据库。

同账号在连接同一部署服务的设备上可恢复数据；当前localhost预览保存在这台电脑，不代表已经上线公网。SQLite适合单实例部署，不能把无持久磁盘的函数环境当长期存储。密码使用scrypt加盐摘要，会话保存在HttpOnly Cookie；AI接口也要求登录和同源请求。
